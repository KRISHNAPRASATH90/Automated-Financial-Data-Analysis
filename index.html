Automated Financial Data Analysis

A Python and MySQL project for cleaning, analysing financial transaction data and generating visual reports.

Project Overview

Developed a financial data analysis and reporting system using Python and MySQL. The project extracts data from five relational database tables, performs data cleaning and integration, analyses spending patterns, and generates visual reports using Matplotlib.

Python MySQL Pandas Matplotlib Schedule

Data Cleaning & Analysis

  • Handled missing values and duplicate records.
  • Standardised transaction statuses and currency codes.
  • Validated financial data and integrated five tables.
  • Analysed monthly expenses and category-wise spending.
  • Compared top merchants and budget versus actual expenses.

Visual Analysis Reports

Four reports generated using Python and Matplotlib.
